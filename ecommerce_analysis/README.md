亚马逊电商销售与退货分析看板 (Amazon E-commerce Sales & Returns Dashboard)
项目简介
本项目基于阿里云天池公开的亚马逊仿真电商销售数据集（(https://tianchi.aliyun.com/dataset/216853)），提供了一套从数据质量检查、业务指标计算到多维可视化看板的完整数据分析解决方案。
项目包含两个核心部分：
  1.Python 自动化分析脚本：负责数据清洗、字段识别、自动化数据质量检测，并生成结构化 Excel 分析报告。
  2.可视化分析看板：基于分析结果制作的多维业务看板（销售趋势、订单漏斗、品类贡献、地区分布、折扣与退货关系）。
⚠️ 声明：数据为仿真生成，分析结论仅用于技术交流与学习展示，不代表真实商业环境。

核心功能
1. 自动化数据质量报告 (data_quality_report.xlsx)
  脚本会自动对源数据执行严格的健康检查，并输出汇总表：缺失值与重复行检查、数据类型推断与格式检查、负数与异常值 (IQR) 筛查、文本一致性检查（首尾空格、大小写变体等）、字段识别：自动匹配并识别日期、金额、销量、品类等关键业务字段。
2. 销售与退货业务分析 (sales_analysis_report.xlsx)
   生成多张结构化业务报表，为看板提供底层数据：整体概览：总销售额、订单数、客单价、产品数。销售趋势：按月/季度聚合的金额与订单量趋势。区域与品类分析：按国家/州/品类/品牌维度的表现排名。退货专项分析：对比 Returned 与 Delivered 组在金额、折扣、单价上的分布差异。分组退货率计算：按品类、品牌、价格区间、折扣区间计算去重后的订单退货率。
3. 可视化看板
环境依赖：请确保你的 Python 环境版本在 3.8 以上，pandas>=1.5.0，openpyxl>=3.1.0
数据局限性说明：金额口径：TotalAmount 字段与 Quantity * UnitPrice 存在差异，且包含 Tax、Discount 等复杂计算，需结合业务字典确认。地理信息：部分 Country 与 City 字段存在不匹配（仿真数据随机生成导致），建议以 State 为主要地理分析维度。订单粒度：当前数据中 OrderID 唯一，假定一行即为一笔独立订单，但真实电商环境需考虑订单商品行（Line Item）的拆解。
